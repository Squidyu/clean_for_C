Windows C Drive Cleaner - 病毒误报解决方案
============================================

问题说明
--------
您的程序被误报为病毒是正常现象，这是因为：
1. 程序需要访问系统目录和删除文件
2. PyInstaller 打包的程序容易被误判
3. 缺少数字签名

解决方案（按推荐顺序）
--------------------

方案1: 添加到杀毒软件白名单（最简单有效）
Windows Defender:
- 设置 > 更新和安全 > Windows 安全中心
- 病毒和威胁防护 > 管理设置
- 添加或删除排除项
- 添加文件: Windows_C_Drive_Cleaner.exe
- 添加文件夹: 程序安装目录

其他杀毒软件:
- 360安全卫士: 添加到信任区
- 腾讯电脑管家: 添加到信任列表
- 火绒安全: 添加信任项

方案2: 使用优化版本（已构建）
已为您构建了减少误报的版本：
- 关闭了 UPX 压缩
- 添加了版本信息
- 分离了资源文件

文件位置: dist/Windows_C_Drive_Cleaner/Windows_C_Drive_Cleaner.exe

快速使用步骤
------------
1. 运行 dist/Windows_C_Drive_Cleaner/add_to_whitelist.bat
2. 运行 install_safe.bat 安装程序
3. 从开始菜单启动程序

安全验证
--------
1. 源代码完全开源，可审查安全性
2. 可以上传到 VirusTotal.com 进行扫描
3. 可以在虚拟机中测试

技术说明
--------
- 程序仅删除临时文件和垃圾数据
- 不会修改系统核心文件
- 用户确认后才删除文件
- 使用 Python + Tkinter 开发

如果仍有问题
----------
1. 查看"解决病毒误报指南.md"详细说明
2. 使用 virus_check.py 进行在线扫描
3. 在虚拟机中测试程序运行
4. 检查源代码确认安全性

联系方式
--------
如有疑问，请检查源代码或联系开发者。

注意：这是合法的系统清理工具，误报是正常现象。
